# spec-generator

Skill de OpenCode para crear y revisar specs del sitio Contrato Empleada de Hogar.

- Ubicación: `.agents/skills/spec-generator/`
- Ficheros: `SKILL.md` (instrucciones) y `spec-template.md` (plantilla).
- Activación: se carga sola cuando pides una spec, o con la herramienta `skill`.
- Salida: `specs/NNN-<nombre>/spec.md`.

`SKILL.md` es la fuente de verdad. Para cambiar el comportamiento, edita ese
fichero y, si cambia la estructura de la spec, `spec-template.md`.
